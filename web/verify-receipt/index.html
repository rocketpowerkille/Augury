Verify a settlement receipt

Paste a QoreChain RDK settlement receipt (version 2). This page asks Augury's SettlementReceipts contract on the QoreChain EVM to rebuild the receipt's anchor message and check its ML-DSA-87 signature against the rollup creator's key, which the contract reads from the chain with pqcKeyStatus and checks with pqcVerify. No key is taken from the receipt.

This proves the creator's registered post-quantum key signed exactly these anchor fields. It does not prove QoreChain recorded the anchor: that is native chain state, which browsers cannot query. packages/node/scripts/settle.ts checks it against a node.
